# JESSICA FANSITE ARCHIVE

Black-and-gold Jessica Jung fan photo and fancam archive by RAINYYANGG.

Features: responsive photo gallery, search, year and type filters, photographer credits, original/licensed/source-link categories, browser-local favorites, theme toggle, event timeline.

To add photos or videos, edit `data.js` and add objects to `window.ARCHIVE_ITEMS`. Use only your own or explicitly licensed images. For others, add source links instead of rehosting their work. Keep photographers' watermarks and credits.

To publish: GitHub repository Settings > Pages > Deploy from a branch > main > / (root) > Save.

Unofficial fan project, not affiliated with Jessica Jung.
